# ニトリ電動ベッド比較ビューア

ニトリの電動ベッドを、  
「実寸」「重量」「モーター数」「必要設置スペース」まで含めて比較できる  
横スクロール型HTMLビューアです。

---

# このビューアでできること

- 電動ベッドの実寸比較
- 設置スペース比較
- 2モーター / 3モーター比較
- 介護対応比較
- セミダブル比較
- 重量比較
- 長時間利用向き比較

---

# 特徴

## 大画面比較に最適化

- 横スクロール対応
- 見出し固定
- 製品名列固定
- 高速検索
- ワンクリックソート

大型モニターやiPad Proでの比較を想定しています。

---

# 含まれる情報

| 項目 | 内容 |
|---|---|
| 実寸サイズ | 幅・奥行・高さ |
| 重量 | kg |
| モーター数 | 1〜3 |
| 高さ昇降 | 対応有無 |
| 必要設置スペース | 比較用計算値 |
| 用途 | 音楽・介護・長時間利用など |
| 特徴 | C型/F型など |
| 公式リンク | 各製品ページ |

---

# 使い方

## 検索

画面上部の検索欄に：

- 3M
- セミダブル
- 介護
- C
- iPad
- Jazz

などを入力すると、
該当モデルだけ表示されます。

---

## ソート

列見出しクリックで：

- 幅順
- 奥行順
- 重量順
- モーター数順

などに並べ替え可能。

# 必要設置スペースについて

必要設置スペースは
公式値ではありません。

比較検討用の計算目です。

---

## 計算条件

### 最小目安

- 幅 + 20cm
- 奥行 + 10cm

### 余裕目安

- 幅 + 80cm
- 奥行 + 20cm

# この比較ビューアの思想

電動ベッドは、
単なる「寝具」ではなく、

## 可動する身体インターフェース

である。

という考え方で整理しています。

- 長時間視聴

- 将来介護
- 起き上がり補助
- 生活導線

---

# C型とF型

| 型番 | 特徴 |
|---|---|
| F | フラット・シンプル |
| C | 棚・コンセント付き |

C型は：

- iPad
- DAC
- メガネ
- リモコン
- 充電器

などを置けるため、
長時間利用向き。
